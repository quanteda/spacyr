# An R wrapper to the spaCy NLP system

An R wrapper to the Python (Cython) spaCy NLP system, from
<https://spacy.io>. Nicely integrated with quanteda. spacyr is designed
to provide easy access to the powerful functionality of spaCy, in a
simple format.
